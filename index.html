S2Recomp

A static recompilation of a 2005 PS2 life-sim. Insert your own PAL disc, and the installer builds a native Windows version from it.

--:--Disc SLES-53718

Before / after slider

Drop a broken capture here and this becomes a drag slider comparing the broken render with the fixed one.

How it works

Your discPAL ISO you own
→
ExtractSYSTEM.CNF, main ELF, data files
→
Analyzefunction list, jump tables, MMIO
→
Recompileone C++ file per guest function
→
Native .exeruntime + recompiled code

Built on PS2Recomp. The full write-up comes from the project's recompilation playbook.

Fan project. Not affiliated with or endorsed by Sony Interactive Entertainment or Electronic Arts. No game files are distributed; you need your own disc.
