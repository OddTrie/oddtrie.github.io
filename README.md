# OddTrie

Personal website for OddTrie’s mods, ports, apps, and other projects.

## GitHub Pages

Publish this folder at the root of the `OddTrie/oddtrie.github.io` repository.
In repository Settings → Pages, select **Deploy from a branch**, **main**, and **/ (root)**.

Website: https://oddtrie.github.io

## Editing

Edit `index.html` to update the website. No build step is needed.
Artwork is illustrative concept art. OddThunk is a working title, and the PS2 recomp is in progress.
